# 0.1S

**Демонстрационное desktop-приложение для учёта товаров и поступлений на склад.**

Приложение позволяет вести каталог товаров, оформлять документы поступления и отслеживать остатки. Проект создан как пример разработки настольного приложения на C# с WPF, MVVM и локальной базой SQLite.

**Репозиторий:** [Next-25/0.1S](https://github.com/Next-25/0.1S)

## Возможности

- **Каталог товаров:** создание, редактирование и удаление товаров; в списке отображаются цена и остаток.
- **Документы поступления:** создание и редактирование документа с номером, датой и контрагентом.
- **Табличная часть:** добавление товаров и указание количества; цена фиксируется в строке документа, суммы строк и итог документа рассчитываются автоматически.
- **Учёт остатков:** остатки пересчитываются по сохранённым документам поступления, в том числе после редактирования или удаления документа.
- **Локальное хранение:** данные сохраняются в SQLite; база создаётся при первом запуске приложения.

## Запуск

Для сборки и запуска потребуется **Windows** и установленный **.NET 10 SDK**.

```powershell
git clone https://github.com/Next-25/0.1S.git
cd 0.1S
dotnet run --project .\_01S.csproj
```

Чтобы только собрать приложение:

```powershell
dotnet build .\_01S.slnx
```

При первом запуске приложение создаёт локальную базу `app.db`. Путь к ней задаётся строкой подключения SQLite `Data Source=app.db` и зависит от рабочей папки процесса.

## Как устроено приложение

Экранные представления отделены от логики с помощью MVVM. `App.xaml.cs` настраивает внедрение зависимостей и подключение к SQLite, `NavigationService` переключает экраны, а `StockService` пересчитывает остатки на основе документов поступления. Данные о документе и его строках связаны через Entity Framework Core.

## Область демонстрации

Текущий интерфейс предназначен для демонстрации каталога товаров и учёта поступлений. Приложение не является готовой многопользовательской системой складского учёта.
